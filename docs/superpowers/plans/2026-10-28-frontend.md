# Frontend refresh plan

User delegates full frontend redesign, theme choices and animation; implement without design checkpoint.
Goal: polished, coherent Thai/English knowledge workspace across all five screens, retaining existing backend and private access.
Design: slate canvas, crisp elevated surfaces, generous typography, an accent-driven knowledge constellation as the memorable element. Colors: light #f5f7fb / #ffffff / #15233b, dark #101722 / #182233 / #e6edf7; accents ocean #126b99, iris #7453b8, forest #287b62, rose #b74969, amber #99600b. Segoe UI/Tahoma, no remote font dependency. All controls keyboard accessible, motion optional.

- [ ] Persist validated appearance preferences: system/light/dark, five accents, comfortable/compact, reduced motion. Apply prepaint to avoid theme flash.
- [ ] Accessible shared dialog, appearance panel, command search with keyboard shortcut, mobile navigation, loading/toast feedback.
- [ ] Polish overview, library, AI answer, task board, imports and transcript. Add sorting, reset filters, copy/export and keyboard submit. Retain original data behavior.
- [ ] Test preferences, TypeScript, existing suite, build and local API smoke; independent code review; publish existing private Site.

Constraints: preference storage only, never chat data or API secrets. No fake loading progress. Follow OS reduced motion even if in-app motion enabled. Unsupported clipboard errors are visible. Browser automation currently unavailable (inventory empty); report visual QA limit.
